# Roboto

Variable WOFF2 fonts, normal and italic (weights 100–900), with Latin and Cyrillic
subsets. Served locally; the application makes no Google Fonts requests.

Source: https://fonts.google.com/specimen/Roboto
License: SIL Open Font License 1.1; see OFL.txt.

Retrieved from the Google Fonts CSS API on 2026-09-24. Unicode ranges in
src/styles/fonts.css match the distributed subsets. Other scripts use the system
fallback family.
